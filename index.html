QA Toolkit: Privacy Policy

Last updated: 26 October 2026

QA Toolkit is an internal quality-assurance tool for RentCafe APv3 (Online Leasing) and RPv3 (Resident Portal) pages. This policy explains what the extension handles and where it goes.

Where it runs

Only on RentCafe portal pages (rentcafe.com, securecafe.com and RentCafe QA domains) and on localhost for development. On any other website it does nothing.

What it handles

  • Test data it generates: fictional test people (names, test emails, test phone numbers, test SSNs on QA only) used to fill forms, and their application progress (prospect id, property, status) read from the portal page.
  • Page diagnostics: failed or error API calls, console errors and on-screen error messages, analytics and cookie-consent status of the portal page, used to help testers report problems. Sensitive values (card numbers, SSNs, phone numbers, emails, tokens) are masked.
  • Screenshots: only when the tester creates a problem report or a payment failure is detected, and only if the tester allowed screenshots.

Where it is stored

Only in the tester's own browser: test people and preferences in the extension's local storage, diagnostics and screenshots in session storage that is cleared when the browser closes. The tester can delete the test-people history at any time from the history page.

What is shared

Nothing. The extension makes no network requests of its own, contains no analytics or tracking, loads no remote code, and does not sell or transfer any data. A problem report leaves the browser only when the tester chooses to copy, download or paste it.
